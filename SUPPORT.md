# Support

For usage questions:

1. Read the README.
2. Check the documentation.
3. Search existing GitHub issues.
4. Open a new issue with a minimal reproducible example if no answer exists.

For security vulnerabilities, use SECURITY.md, not a public issue.

When asking for help, include the SentinelFlow version/commit, operating environment, relevant configuration shape and logs with all credentials/redacted secrets removed.
