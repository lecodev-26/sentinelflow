# SentinelFlow Roadmap

**Release status:** V5.0.1 is the latest published stable release. V6 is active development on the `v6` branch and is not yet a stable/GA release.

## V5.0.1 — current stable GA line

V5 adds intelligent AI execution capabilities on top of the V4 enterprise foundation:

- intelligent request understanding and adaptive routing
- agent runtime and universal tool gateway
- tenant/project-isolated memory and knowledge/RAG
- AI Security 2.0
- predictive AI FinOps
- AI observability and evaluation
- prompt lifecycle management
- multimodal request primitives
- AI governance and plugin extensibility
- global routing and self-healing primitives
- learning signals and Zero Trust AI
- capacity/autoscaling foundations

See [V5 architecture](v5/ARCHITECTURE.md), [V5 GA](v5/ga/GA.md), and [production readiness](v5/ga/production-readiness.md).

## V6 — active development

V6 work takes place on the `v6` branch. This branch is not a published stable release; its scope and release date remain subject to implementation, CI, security and operational validation. Only verified changes should be recorded as V6 release notes.

Future milestones are driven by production usage, contributor feedback, provider evolution, operational evidence and explicit security/reliability requirements. New milestones will be published as they are designed and validated.
